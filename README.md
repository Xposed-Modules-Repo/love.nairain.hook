## 环境要求

- Android 9（API 28）及以上
- 支持 libxposed 102 API 的框架，例如 LSPosed
- 已解锁/root 设备

---

## 使用教程

1. 安装模块 APK
2. 在 LSPosed 中启用 Rain
3. 在模块内的“应用”页面或 LSPosed 中选择作用域
4. 按框架提示重启目标应用
5. 也可参考应用内使用教程
