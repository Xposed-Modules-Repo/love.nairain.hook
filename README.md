## 关于 Rain

Rain 是一个基于现代 Xposed API 的免费模块，为已适配应用提供去广告、界面精简和本地功能解锁等功能。管理界面采用 Jetpack Compose + Miuix。

- **减少广告干扰**：跳过部分应用的开屏广告，移除已适配的应用内广告与推广内容。
- **精简应用界面**：清理部分应用的营销入口和冗余布局。
- **解锁本地功能**：调整部分应用的客户端状态。

## 环境要求

- **Android 10及以上**：模块 APK 的最低安装要求为 Android 9，但部分功能需要 Android 10 及以上。
- **支持 libxposed API 102 的框架**：例如支持该 API 的 LSPosed 版本。

## 使用教程

1. **安装模块**：从发布页选择所需版本并安装。
2. **启用模块**：打开 LSPosed，在模块列表中启用。
3. **选择作用域**：在 LSPosed 推荐作用域中勾选需要使用的目标应用，也可在 Rain 的「应用」页面管理已显示应用的作用域。
4. **重启目标应用**：强制停止目标应用，再重新打开；如框架有额外提示，请按提示操作。
5. **检查状态**：打开 Rain，查看框架连接状态及应用启用情况；更多说明可在「设置 → 使用帮助」中查看。

**更新 Rain 后，也需要强制停止并重新打开目标应用，才能使新版本生效。**

## 常见问题

### 应用显示「未适配」是什么意思？

已安装版本超出了模块标注的支持范围。请核对应用内适配说明，使用支持的应用版本或等待模块更新。

### 如何反馈问题？

反馈时请提供 Rain 版本、系统与框架版本、目标应用版本，以及具体问题和复现步骤，便于排查。
